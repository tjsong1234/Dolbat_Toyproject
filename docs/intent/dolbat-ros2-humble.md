# 돌밭 ROS2 Humble 전환 — 확정 의도

확정일: 2026-11-27. 사용자가 범위에 대해 "맞아"로 확인했다.

## 목적과 대상

기존 CPU 기반 돌밭 Toy Project의 1~4주차 처리 단계를 ROS2 노드로 분리해 Ubuntu 22.04·ROS2 Humble 환경에서 재현하고 실행할 수 있게 한다. 주차별 기능·입출력·연결 관계를 설명할 수 있고, 기존 녹화 영상의 결과를 유지하는 것이 목적이다.

## 확정 범위

- 주차별 노드의 역할, 토픽·메시지·좌표계·실행 방법·검증 절차를 명확히 한다.
- 기존 ROI·BEV·차선 검출·B-spline 경로·Pure Pursuit 계산 결과를 유지한다.
- ROS2 통신 비용을 포함한 처리 성능을 측정하고 평균 24FPS 가능 여부를 검증한다.
- Windows 프로젝트와 이전 제출물은 보존한다. 현재 Ubuntu는 듀얼부팅으로 설치되어 있다.

## 하지 않을 일

- 실제 차량 구동 및 실제 조향 장치 명령 전송
- 실시간 카메라 연결
- 딥러닝 도입 또는 차선 인식 알고리즘 재설계
- 시스템 Python을 기존 Windows 프로젝트 버전에 맞춰 교체

## 후속 요청으로 확대된 실행 권한

확인 직후 사용자는 `https://github.com/tjsong1234/Dolbat_Toyproject.git`에 연결해 커밋·푸시하고, Ubuntu에서 pull 후 실행할 수 있는 ROS2 패키지로 만들어 달라고 직접 요청했다. 이에 범위는 계획 작성에 그치지 않고 실제 구현·빌드/실행 스크립트·테스트·GitHub 게시까지 확대되었다. 기존 계획 단계의 종료 대신 이 직접 실행 요청을 수행한다.

실제 Linux/ROS2 실행 검증이 불가능하면 이를 완료로 보고하지 않는다. 의존성·빌드가 필요한 최초 설치와 이후 pull/재빌드·실행을 구분해 설명한다.
